# Examples

Example source media for trying Multiverse.

**Policy (spec §3):** only user-owned or public-domain media is committed
here. The software never depends on copyrighted source material — supply
your own clip locally:

```bash
uv run multiverse generate path/to/your-video.mp4
```

Recommended source: 2–15 seconds, single shot, one clear subject,
24–30 fps. Multiverse works on a 5-second moment by default.
