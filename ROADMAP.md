# Roadmap

V0 build order (spec §53). Go/no-go gate: the §52 spike — four H3 Max
reference-to-video variants in a synchronized 2×2 grid must read as
**one event occurring in four realities**.

- [ ] **Phase 0 — visual proof**: source clip, four H3 renders,
      hand-authored world prompts, compose 1→4.
- [ ] **Phase 1 — cinematic proof**: sixteen worlds, 1→4→16 compositor,
      procedural 16→64→256, zoom-to-world, recursive ending → final X film.
- [ ] **Phase 2 — repo**: H3 adapter, CLI, SceneSpec, UniverseTree,
      persistent runs, exports.
- [ ] **Phase 3 — web UI**: upload, generate 4, expand, click branch, export.
- [ ] **Phase 4 — agent native**: doctor, JSON commands, AGENTS.md,
      RUN_WITH_AGENT.md, credential handling.
- [ ] **Phase 5 — distribution loop**: participation export, branch-by-node,
      share captions, examples.
- [ ] **Phase 6 — additional renderers** (post-launch only).
- [ ] **Phase 7 — live mode** (separate future milestone).

Launch criteria: spec §54.
